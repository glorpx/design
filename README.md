# @glorpx/design

A modern, type-safe React component library built with TypeScript and Tailwind CSS. Provides a foundation for building consistent, accessible user interfaces.

## Features

- **TypeScript First**: Full type safety with strict mode enabled
- **Dual Output**: ESM and CommonJS formats for maximum compatibility
- **Tailwind CSS**: Utility-first styling with built-in theme support
- **Tested**: Comprehensive test suite with Vitest and 80%+ coverage
- **Accessible**: WCAG compliance built into component design
- **Tree-shakeable**: Unused components are removed during bundling

## Installation

```bash
npm install @glorpx/design react react-dom
# or
pnpm add @glorpx/design react react-dom
```

## Requirements

- Node.js 18+
- React 18+
- React DOM 18+

## Usage

```typescript
import { version } from "@glorpx/design";

console.log(version);
```
